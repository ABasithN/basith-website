# THE OTHER SIDE v0.7

A standalone HTML/CSS/JS interactive prototype.

## What is included
- Locked landing proposition, without the "interactive experience" line.
- Agency/Client identity selection and role reversal.
- Three experiences: The Brief, The Deadline, The Campaign.
- Both role directions are represented through the role reversal.
- Email, WhatsApp and Slack interfaces.
- User choices are visibly typed and sent as outgoing messages.
- Email is threaded. New incoming email appears as a new top-of-thread event while history remains.
- WhatsApp and Slack retain conversation history.
- Central attention notifications guide the user to the next channel.
- Active channel lifts visually and receives attention treatment.
- Desktop laptop hero with atmospheric desk-like environment.
- Mobile changes to a full-screen communication experience rather than shrinking the laptop.
- No external libraries or build process.

## Run
Unzip and open `index.html` in a modern browser.

## Production next step
Upload the three files to Cloudflare Pages, Netlify, GitHub Pages, or another static host. The site does not require a server.

## Creative note
The landing page deliberately does not say "An interactive experience". The premise should do the selling.
